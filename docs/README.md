# Documentation Index

The repository documentation has one source of truth for each kind of information:

- `../README.md`: current product capabilities and how to run the project.
- `../ROADMAP.md`: the 16-week plan and completion status.
- `weeks/`: weekly understanding, evidence, failures, and retrospectives.
- `specs/`: acceptance criteria written before implementation.
- `adr/`: durable architecture decisions and their trade-offs.
- `diagrams/`: system context, execution flow, state machine, and trust boundaries.
- `prompts/`: reusable AI collaboration prompts, not raw chat transcripts.
- `ai-debt.md`: code or concepts that still require personal verification.

Do not duplicate the same content across multiple files. Link to its source instead.
